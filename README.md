# 👾 Bicho Papão

Um jogo 2D estilo plataforma desenvolvido em **Python + Pygame**, ambientado em um mundo medieval cheio de desafios, inimigos e um boss final.

O jogador precisa atravessar diferentes cenários, desviar de inimigos, sobreviver com suas vidas limitadas e chegar até o boss final para encarar o Bicho Papão.

---

## 🎮 Gameplay

- Controle do personagem principal em um mundo 2D
- Sistema de pulos e movimentação lateral
- Inimigos no cenário com colisão
- Boss final com batalha intensa
- Sistema de vidas (game over ao perder todas)
- Telas de transição (incluindo Game Over)

---

## 🏰 Cenários

O jogo conta com diferentes backgrounds progressivos:

- 🌄 Fase inicial (ambiente externo)
- 🏚️ Fase intermediária
- 🏰 Castelo medieval
- 👹 Sala do Boss (Bicho Papão)

---

## 💀 Game Over

Ao perder todas as vidas, o jogador é levado para uma tela de **Game Over** com estética medieval e trilha sonora temática.

---

## 🛠️ Tecnologias

- Python 3
- Pygame
- Sprites 2D
- Sistema de colisão próprio
- Estrutura modular de código
